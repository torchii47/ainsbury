Before you upload

  • Your homepage must be called index.html.
  • Use lowercase file names with no spaces, e.g. about-me.html not About Me.html.
  • Link to files using relative paths, e.g. images/logo.png, not a path from your own computer.
  • Give every image an alt description.
  • Compress images before uploading so pages load quickly.
  • Run your pages through the HTML and CSS validators and fix any errors.
  • Keep a backup copy of your site files on your own drive.

Every page should have

  • <!DOCTYPE html> and <html lang="en">
  • <meta charset="utf-8"> and the viewport meta tag
  • A unique <title>
  • Navigation back to your homepage
