1.3.1 Networks and topologies

A network is two or more computers connected together so they can share data and resources.

LAN (local area network)WAN (wide area network)
AreaA small geographical area, e.g. one building or siteA large geographical area, e.g. across a country or the world
InfrastructureHardware is owned and managed by the organisationUses third-party infrastructure, e.g. leased telecoms lines, satellites
ExamplesA school network, a home networkA bank connecting its branches; the Internet is the largest WAN

Factors that affect network performance

FactorEffect
BandwidthThe amount of data that can be transmitted per second. Higher bandwidth = more data, faster transfers.
Number of users / devicesMore devices sharing the bandwidth = less each, and more data collisions, so slower.
Transmission mediaFibre optic is faster and carries data further than copper cable; wireless is usually slower than wired.
Interference and errorsWalls, distance and other devices weaken wireless signals; errors mean data must be re-sent.
LatencyThe delay before data starts to arrive. High latency (e.g. data travelling a long way) makes video calls and games lag.
TopologyHow devices are connected; e.g. a mesh has more routes so traffic can avoid busy links.

Client-server and peer-to-peer

Client-serverPeer-to-peer
RolesA server provides services (files, email, web pages, logins) that clients requestAll computers are equal: each can share its files and resources directly with the others
AdvantagesFiles and backups managed centrally; security and user accounts controlled in one place; software updated centrallyCheap and easy to set up; no expensive server or specialist needed; no single point of failure
DisadvantagesServers and network staff are expensive; if the server fails, clients lose accessFiles are spread out, so hard to back up and manage; each user manages their own security; a computer that's switched off can't share
UseSchools, businesses, websitesSmall home networks, file-sharing apps

Network hardware

HardwareJob
NIC (network interface controller/card)Lets a device connect to a network (wired or wireless). Each NIC has a unique MAC address.
SwitchConnects devices on a LAN. Receives data and sends it only to the device it is addressed to, using the MAC address.
RouterSends data between different networks, e.g. between a LAN and the Internet, using IP addresses. Chooses the route for packets.
WAP (wireless access point)Lets wireless devices connect to a wired network.
Transmission mediaWhat carries the data: copper (Ethernet) cable, fibre optic cable (light), or radio waves (wireless).

A home "router" is usually a router, switch and WAP in one box.

Star and mesh topologies

StarMesh
AdvantagesIf one cable or device fails, the rest keep working; easy to add devices; fast, because the switch sends data only where it's needed; few collisionsNo single point of failure: if one link fails, data takes another route; can carry lots of traffic; very reliable
DisadvantagesIf the central switch fails, the whole network fails; needs lots of cable, which costs moreExpensive: lots of cabling and connections (a full mesh of n devices needs n(n−1)/2 links); hard to set up and maintain

Wireless mesh networks (e.g. home mesh Wi-Fi) avoid the cabling cost: each node passes data on to the others.

LAN
Local area network: a network over a small geographical area, using hardware owned by the organisation.
WAN
Wide area network: a network over a large geographical area, often using third-party infrastructure.
Bandwidth
The amount of data that can be transmitted over a network in a given time.
Client-server network
A network in which servers provide services and resources that clients request.
Peer-to-peer network
A network in which all computers have equal status and share resources directly with each other.
Switch
Connects devices on a LAN and sends data only to the device it is addressed to, using MAC addresses.
Router
Sends data packets between different networks, using IP addresses.
WAP
Wireless access point: allows wireless devices to connect to a wired network.
NIC
Network interface controller: hardware that allows a device to connect to a network.
Star topology
A network layout in which every device is connected to a central switch.
Mesh topology
A network layout in which devices are connected to many (or all) other devices, giving several routes for data.

1.3.1 The Internet

The Internet is a worldwide collection of interconnected networks. The World Wide Web is a service that runs on it: web pages accessed by browsers.

DNS: the Domain Name System

Computers find each other by IP address, but people remember names. DNS turns a domain name into an IP address.

1You type a URL, e.g. www.ocr.org.uk
→
2The browser sends a request to a DNS server
→
3The DNS server looks up the domain name and returns its IP address (or asks another DNS server)
→
4The browser uses the IP address to request the page from the web server

If no DNS server has the name, an error is returned. Results are cached so the next lookup is quicker.

dns_cache = {"ocr.org.uk": "203.0.113.10"}
dns_server = {"ocr.org.uk": "203.0.113.10", "bbc.co.uk": "203.0.113.25",
              "ainsbury.art": "198.51.100.7"}

def lookup(domain):
    if domain in dns_cache:
        return dns_cache[domain] + " (from cache)"
    if domain in dns_server:
        dns_cache[domain] = dns_server[domain]
        return dns_server[domain] + " (from DNS server)"
    return "not found: the browser shows an error"

for site in ["bbc.co.uk", "bbc.co.uk", "ocr.org.uk", "nosuchsite.xyz"]:
    print(site, "->", lookup(site))

bbc.co.uk -> 203.0.113.25 (from DNS server)
bbc.co.uk -> 203.0.113.25 (from cache)
ocr.org.uk -> 203.0.113.10 (from cache)
nosuchsite.xyz -> not found: the browser shows an error

TermMeaning

1.3.2 Wired, wireless and addressing

Wired (Ethernet)Wi-FiBluetooth
HowCopper or fibre optic cableRadio waves to a WAPShort-range radio between two devices
Speed / reliabilityFastest and most reliable; little interferenceSlower; affected by walls, distance and other devicesSlow; short range (about 10 m)
MobilityDevice must be near a socketMove around freely within rangePairs devices close together, e.g. earbuds
SecurityMust physically plug in to interceptSignals can be intercepted, so must be encryptedShort range limits who can connect
Cost / set-upCables cost money and are hard to installCheap and easy to add devicesBuilt into most devices

Encryption

Encryption scrambles data using a key so that if it is intercepted it can't be understood. Only a device with the correct key can decrypt it. Wi-Fi traffic is encrypted (e.g. WPA2/WPA3), so the password is needed to join. HTTPS encrypts web traffic.

IP and MAC addresses

IP addressMAC address
What it identifiesA device on a network / the Internet. Used by routers to route packets between networks.A device's NIC, uniquely. Used by switches to send data to the right device on a LAN.
AssignedBy the network when the device connects; can change (dynamic) or be fixed (static)At manufacture; doesn't normally change
FormatIPv4: 32 bits, written as four denary numbers 0–255, e.g. 192.168.0.12
IPv6: 128 bits, written in hexadecimal, e.g. 2001:0db8:85a3::8a2e:0370:7334		48 bits, written as 12 hexadecimal digits in pairs, e.g. 3C:5A:B4:01:9F:2E

IPv6 was introduced because IPv4 only allows about 4.3 billion addresses, which isn't enough for every device in the world.

Standards

Standards are agreed rules and specifications for hardware and software (e.g. the size of an Ethernet plug, how Wi-Fi signals work). They allow hardware and software from different manufacturers to work together.

Ethernet
A standard for wired network connections.
Encryption
Scrambling data using a key so that it can't be understood if intercepted.
IP address
An address given to a device on a network, used to route data between networks.
MAC address
A unique 48-bit hexadecimal address assigned to a network interface controller when it is made.
Standards
Agreed rules for hardware and software so that products from different manufacturers work together.

1.3.2 Protocols and layers

A protocol is a set of rules for how devices communicate and how data is transmitted across a network.

ProtocolStands forPurpose
TCP/IPTransmission Control Protocol / Internet ProtocolTCP splits data into packets, numbers them, checks they all arrive and reassembles them in order. IP addresses and routes each packet to its destination.
HTTPHypertext Transfer ProtocolUsed by browsers to request and receive web pages from web servers.
HTTPSHypertext Transfer Protocol SecureHTTP with encryption, so data such as passwords and card details can't be read if intercepted.
FTPFile Transfer ProtocolTransfers files between computers, e.g. uploading a website to a web server.
POPPost Office ProtocolDownloads email from a mail server to one device, then usually deletes it from the server.
IMAPInternet Message Access ProtocolAccesses email that stays on the server, so it is synced across all your devices.
SMTPSimple Mail Transfer ProtocolSends email from a client to a mail server, and between mail servers.

Match the protocol

Entering your bank card details on a shopping website.

Pressing Send on an email.

Reading the same inbox on your phone and your laptop.

Uploading the files of your website to a web server.

Splitting a file into packets and checking they all arrived.

Downloading emails to one computer so they can be read offline.

Layers

Networking is split into layers. Each layer has a specific job and its own protocols. A layer only uses the layer directly below it and provides a service to the layer directly above it. The TCP/IP model has four layers:

LayerJobProtocols
ApplicationProvides network services to applicationsHTTP, HTTPS, FTP, SMTP, IMAP, POP
TransportSplits data into packets, numbers and reassembles them, checks for errorsTCP
InternetAdds IP addresses and routes packets across networksIP
LinkSends the data over the physical network hardwareEthernet, Wi-Fi

Benefits of layers: a big, complex problem is broken into smaller parts (decomposition); each layer can be developed and changed independently without affecting the others; different manufacturers can make hardware and software for one layer that works with the rest (standards); it's easier to find and fix problems.

★ EXAM TIP: POP vs IMAP

A user who reads email on several devices needs IMAP, because the email stays on the server and is synchronised. POP downloads it to one device. Both receive email; SMTP sends it.

Protocol
A set of rules that govern how data is transmitted and how devices communicate on a network.
TCP/IP
The protocols that split data into packets, address and route them, and reassemble them in order at the destination.
HTTPS
The secure, encrypted version of HTTP, used to transfer web pages.
SMTP
The protocol used to send email.
IMAP
An email protocol that keeps mail on the server so it can be accessed from several devices.
Layer
A division of network functionality with its own job and protocols, which works independently of the other layers.

Knowledge organiser

LAN vs WAN

  • LAN: small area, own hardware
  • WAN: large area, third-party infrastructure
  • Internet = biggest WAN

PERFORMANCE

  • Bandwidth
  • Number of users
  • Transmission media
  • Interference / errors
  • Latency

CLIENT-SERVER vs P2P

  • C-S: server provides, clients request; central control; server cost
  • P2P: all equal; cheap; hard to back up

HARDWARE

  • NIC: connects device; has MAC
  • Switch: within a LAN, by MAC
  • Router: between networks, by IP
  • WAP: wireless to wired
  • Media: copper, fibre, radio

INTERNET

  • DNS: domain name → IP address
  • Web server sends pages to clients
  • Hosting: site stored on a server
  • Cloud: remote servers via Internet

TOPOLOGIES

  • Star: central switch; switch fails = all fail
  • Mesh: many routes; reliable; expensive

ADDRESSES

  • IPv4: 4 × 0–255; IPv6: 128-bit hex
  • MAC: 48-bit, 12 hex digits, set at manufacture
  • Encryption: unreadable without key

PROTOCOLS

  • TCP/IP: packets, routing
  • HTTP/HTTPS: web pages (S = encrypted)
  • FTP: files; SMTP: send email
  • POP: download email; IMAP: synced
  • Layers: independent, standard, easier

Exam-style questions

Allow about 35 minutes. Answer each question before you look at its mark scheme.

Give two differences between a LAN and a WAN.

  • LAN covers a small geographical area, WAN covers a large area (1).
  • LAN hardware is owned by the organisation, WAN uses third-party/leased infrastructure (1).

State three factors that can affect the performance of a network.

  • Any three, 1 each: bandwidth; number of users/devices; transmission media; interference; errors/packet loss; latency; distance; topology.

A small dental practice has four computers. Explain one advantage and one disadvantage of using a client-server network instead of peer-to-peer.

  • Advantage: patient files stored/backed up centrally on the server (1) so they are not lost if one computer fails / easier to manage security (1).
  • Disadvantage: a server is expensive to buy/needs a specialist to manage (1) which is a big cost for a small practice / if the server fails no one can access files (1).

Describe the role of a router.

  • Sends/forwards data packets between different networks, e.g. a LAN and the Internet (1).
  • Uses IP addresses to decide the route (1).

Describe how DNS is used when a user enters a web address into a browser.

  • The browser sends the domain name/URL to a DNS server (1).
  • The DNS server looks up the domain name in its database (1).
  • It returns the matching IP address (or passes the request to another DNS server if not found) (1).
  • The browser uses the IP address to contact/request the page from the web server (1).

A school connects its classrooms in a star topology. Explain one advantage and one disadvantage of a star topology for the school.

  • Advantage: if one cable/computer fails the rest of the network keeps working (1) so other classrooms are not affected (1). Accept: easy to add new computers.
  • Disadvantage: if the central switch fails the whole network fails (1) so no classroom can access the network (1). Accept: lots of cable needed, which is expensive.

Compare IP addresses and MAC addresses.

  • Any two linked comparisons, 1 each: MAC is assigned at manufacture, IP is assigned by the network; MAC is permanent, IP can change; MAC used within a LAN by switches, IP used to route between networks; MAC is 48-bit hex, IPv4 is 32-bit denary.

A user reads email on a phone and a laptop. State which protocol should be used to receive email, and explain why. Name the protocol used to send email.

  • IMAP (1) because emails are kept on the server so the inbox is synchronised on both devices (1).
  • SMTP (1).

Explain why HTTPS should be used on a shopping website.

  • HTTPS encrypts the data sent between the browser and the web server (1) so card details/passwords can't be read if intercepted (1).

Explain three benefits of using layers in networking.

  • Any three, 1 each: breaks a complex system into manageable parts; each layer can be changed without affecting others; manufacturers can develop for one layer (compatibility/standards); easier to find and fix errors; each layer has its own protocols.

A café offers Wi-Fi to customers. Discuss the advantages and disadvantages of using wireless rather than wired connections for this.

  • Advantages: customers can connect their own phones/laptops anywhere in the café (1); no cables to install or trip over (1); easy to add many devices (1).
  • Disadvantages: slower/less reliable with many users (1); signals can be intercepted so must be encrypted (1); interference from walls/other devices (1). Max 4.
