Task 1: Pass or fail (selection and validation)

Ask for a test mark out of 50. Keep asking until it is between 0 and 50. Convert it to a percentage and output "Pass" if it is at least 40%, otherwise "Fail".

Show a model solution 
mark = int(input("Mark out of 50: "))
while mark < 0 or mark > 50:
    print("Must be 0 to 50")
    mark = int(input("Mark out of 50: "))
percent = mark / 50 * 100
if percent >= 40:
    print("Pass with", percent, "%")
else:
    print("Fail with", percent, "%")

Must be 0 to 50

Pass with 62.0 %

Task 2: Password strength (string handling)

Write a function that returns True if a password is at least 8 characters long and contains at least one digit and one capital letter.

Show a model solution 
def strong_password(password):
    has_digit = False
    has_upper = False
    for char in password:
        if char.isdigit():
            has_digit = True
        if char.isupper():
            has_upper = True
    return len(password) >= 8 and has_digit and has_upper

for attempt in ["sunshine", "Sunshine", "Sunshine7", "Sun7"]:
    print(attempt, strong_password(attempt))

sunshine False
Sunshine False
Sunshine7 True
Sun7 False

Task 3: Caesar cipher (ASC and CHR)

Write a function that shifts every letter in a message along the alphabet by a given amount, wrapping from Z back to A. Spaces stay as they are.

Show a model solution 
def caesar(text, shift):
    result = ""
    for char in text.upper():
        if "A" <= char <= "Z":
            code = (ord(char) - 65 + shift) % 26 + 65
            result = result + chr(code)
        else:
            result = result + char
    return result

secret = caesar("Meet at noon", 3)
print(secret)
print(caesar(secret, -3))

PHHW DW QRRQ
MEET AT NOON

In ERL you'd use ASC(char) and CHR(code), and MOD 26 to wrap round.

Task 4: High score file (file handling)

Write three name,score lines to a file, then read the file back and output the player with the highest score.

Show a model solution 
scores_file = open("highscores.txt", "w")
scores_file.write("Ana,340\n")
scores_file.write("Raj,410\n")
scores_file.write("Mo,275\n")
scores_file.close()

best_name = ""
best_score = -1
scores_file = open("highscores.txt", "r")
for line in scores_file:
    parts = line.strip().split(",")
    if int(parts[1]) > best_score:
        best_score = int(parts[1])
        best_name = parts[0]
scores_file.close()
print("High score:", best_name, best_score)

High score: Raj 410

Task 5: Noughts and crosses (2D arrays)

A 3 × 3 board is stored in a 2D array. Write a function that returns True if a given player has three in a row, column or diagonal.

Show a model solution 
board = [["X", "O", "X"],
         ["O", "X", "O"],
         ["O", "X", "X"]]

def winner(board, player):
    for i in range(3):
        if board[i][0] == player and board[i][1] == player and board[i][2] == player:
            return True
        if board[0][i] == player and board[1][i] == player and board[2][i] == player:
            return True
    if board[0][0] == player and board[1][1] == player and board[2][2] == player:
        return True
    if board[0][2] == player and board[1][1] == player and board[2][0] == player:
        return True
    return False

print("X wins:", winner(board, "X"))
print("O wins:", winner(board, "O"))

X wins: True
O wins: False

Task 6: Shopping basket (records)

Store each item in a basket as a record with an item name, price and quantity. Output the cost of each line and the total, to 2 decimal places.

Show a model solution 
basket = [
    {"item": "Pen", "price": 1.20, "quantity": 3},
    {"item": "Notebook", "price": 2.50, "quantity": 2},
    {"item": "Ruler", "price": 0.80, "quantity": 1},
]
total = 0
for line in basket:
    cost = line["price"] * line["quantity"]
    total = total + cost
    print(line["item"], "x", line["quantity"], "=", format(cost, ".2f"))
print("Total: £" + format(total, ".2f"))

Pen x 3 = 3.60
Notebook x 2 = 5.00
Ruler x 1 = 0.80
Total: £9.40

A cinema uses a program to manage ticket sales. Adult tickets cost £9 and child tickets cost £6. A screen has 120 seats.

Write an algorithm that asks for the number of adult tickets and the number of child tickets, and outputs the total cost.

  • Input number of adults, cast to integer (1).
  • Input number of children, cast to integer (1).
  • Calculate total = adults × 9 + children × 6 (1).
  • Output total (1).

Refine your algorithm so it keeps asking for the number of adult tickets until it is between 0 and 120.

  • Condition-controlled loop around the input (1).
  • Correct condition: adults < 0 OR adults > 120 (1).
  • Input repeated inside the loop / error message (1).

Give one item of invalid test data and one item of boundary test data for the number of adult tickets.

  • Invalid: e.g. −1, 121, 200 (1).
  • Boundary: 0 or 120 (1).

The number of tickets sold for each of the 7 days of a week is stored in an array sales (index 0 to 6). Write a program that outputs the total tickets sold, the highest number sold on one day, and how many days sold more than 100 tickets.

  • Loop through all 7 elements (1).
  • Running total initialised to 0 and added to (1).
  • Highest initialised (e.g. sales[0] or 0) (1) and updated when a bigger value is found (1).
  • Counter incremented when sales[i] > 100 (1).
  • All three values output after the loop (1).

Write a function seatsLeft(sold) that takes the number of seats sold and returns the number of seats left. If more than 120 have been sold, it should return 0.

  • Function header with parameter sold (1).
  • If sold > 120 return 0 (1).
  • Otherwise return 120 − sold (1).
  • Uses return rather than print (1).

This code should output the average of 5 numbers, but it contains two errors. Identify and correct them.
