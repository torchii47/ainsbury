1.5.1 Operating systems

Systems software runs and manages the computer itself. The most important piece is the operating system (OS), e.g. Windows, macOS, Linux, Android, iOS. Its purpose is to manage the hardware and software of the computer and provide a platform for applications to run, so programs don't each need to know how to control the hardware.

FunctionWhat the OS does
User interfaceLets the user interact with the computer. GUI (graphical user interface): windows, icons, menus and a pointer; easy for beginners. Command-line interface: typed commands; uses fewer resources, faster for experts, can automate tasks with scripts. Others include menu-driven (e.g. a cash machine), touch and voice.
Memory management and multitaskingMoves programs and data into and out of RAM as needed; allocates each program its own area of memory so programs don't overwrite each other; frees memory when a program closes; uses virtual memory when RAM is full. Multitasking: the CPU can only process one instruction at a time per core, so the OS gives each program a short time slice of CPU time in turn, so fast that they appear to run at once.
Peripheral management and driversManages communication with input, output and storage devices (printer, keyboard, webcam). A device driver is software that translates the OS's general instructions into commands the specific device understands. New hardware needs the right driver; drivers are updated to fix bugs.
User managementCreates user accounts with usernames and passwords; controls access rights (what each user can see and change); keeps each user's files and settings separate; logs activity.
File managementOrganises files into a hierarchy of folders/directories; lets users create, name, rename, move, copy, save and delete files; controls file permissions (read-only, read/write); keeps track of where each file is stored on the disk.

Multitasking: a time-slice simulation

Three programs need different amounts of CPU time. The OS gives each one time slice in turn, then puts it at the back of the queue.

queue = [["Browser", 3], ["Music", 2], ["Game", 4]]
tick = 0
while len(queue) > 0:
    task = queue.pop(0)
    tick = tick + 1
    task[1] = task[1] - 1
    if task[1] > 0:
        queue.append(task)
        print("Tick", tick, ":", task[0], "runs,", task[1], "left, back of the queue")
    else:
        print("Tick", tick, ":", task[0], "runs and finishes")

Tick 1 : Browser runs, 2 left, back of the queue
Tick 2 : Music runs, 1 left, back of the queue
Tick 3 : Game runs, 3 left, back of the queue
Tick 4 : Browser runs, 1 left, back of the queue
Tick 5 : Music runs and finishes
Tick 6 : Game runs, 2 left, back of the queue
Tick 7 : Browser runs and finishes
Tick 8 : Game runs, 1 left, back of the queue
Tick 9 : Game runs and finishes

✗ COMMON MISTAKE

  • Saying the OS "manages files" for every function. Learn one specific example for each of the five functions.
  • Confusing a device driver with the device. The driver is software.
Operating system
Systems software that manages the computer's hardware and software and provides a platform for applications.
GUI
Graphical user interface: lets users interact using windows, icons, menus and a pointer.
Command-line interface
A text-based interface where the user types commands.
Multitasking
Running several programs apparently at the same time by giving each a share of CPU time in turn.
Memory management
The OS allocating RAM to programs, moving data in and out of memory and stopping programs overwriting each other.
Device driver
Software that lets the operating system communicate with a specific hardware device.
User management
The OS creating user accounts and controlling each user's access rights.
File management
The OS organising files into folders and letting users create, move, copy, rename and delete them.

1.5.2 Utility software

Utility software is systems software that helps to maintain, optimise and protect the computer. It isn't needed for the computer to run, but it keeps it running well.

UtilityWhat it doesWhy it's useful
Encryption softwareScrambles files or whole drives using a key, so they can only be read by someone with the key.If a laptop or USB stick is lost or stolen, or files are intercepted, the data can't be read.
DefragmentationOver time, files on a magnetic hard disk are split into fragments stored in different places, with gaps where files were deleted. Defragmentation moves the fragments of each file back together and groups the free space together.The read/write head moves less to read a file, so files load faster. Not needed for SSDs: they have no moving parts, so access time doesn't depend on location, and extra writes wear them out.
Data compressionReduces the size of files (lossy or lossless), e.g. zipping a folder.Saves storage space; files are quicker to send and upload.

Other utilities you may meet: backup software, anti-malware, disk clean-up, firewall software.

What defragmentation does

disk = ["A", "B", "A", ".", "C", "B", ".", "A", "C", "."]
print("Before:", " ".join(disk))

blocks = [block for block in disk if block != "."]
blocks.sort()
defragged = blocks + ["."] * (len(disk) - len(blocks))
print("After: ", " ".join(defragged))

Before: A B A . C B . A C .
After:  A A A B B C C . . .

Before, file A is split across three places. After, every file is in one continuous run and all the free space (.) is together.

★ EXAM TIP: DEFRAGMENTATION

For full marks say why it helps: the files' parts are stored next to each other, so the read/write head moves less, so files are accessed faster. And know that it isn't used on SSDs.

Utility software
Systems software that helps maintain, optimise or protect the computer.
Defragmentation
Reorganising a hard disk so the parts of each file are stored together and free space is grouped, making access faster.
Encryption software
A utility that scrambles files or drives so they can only be read with the correct key.
Compression software
A utility that reduces the size of files.

Exam-style questions

Allow about 25 minutes. Answer each question before you look at its mark scheme.

State two functions of an operating system, other than file management.

  • Any two: provides a user interface; memory management; multitasking; peripheral management/drivers; user management.

Describe how an operating system manages memory.

  • Any three, 1 each: moves programs/data into RAM when needed; removes them when no longer needed; allocates memory to each program; prevents programs overwriting each other's memory; uses virtual memory when RAM is full.

Explain how an operating system allows several programs to appear to run at the same time.

  • Each program is given a short slice of CPU time in turn (1) switching so quickly that they appear to run at once (1).

Describe the purpose of a device driver.

  • Software that allows the OS to communicate with a hardware/peripheral device (1) by translating the OS's instructions into ones the specific device understands (1).

Describe three ways the operating system manages users on a school network.

  • Any three: creates/deletes user accounts; usernames and passwords for logging in; sets access rights/permissions, e.g. students can't access staff files; keeps each user's files separate; records/monitors activity.

Explain how defragmentation improves the performance of a hard disk drive.

  • Fragments of each file are moved so they are stored next to each other (1).
  • Free space is grouped together (1).
  • The read/write head has to move less to read a file, so files are accessed faster (1).

Explain why an SSD should not be defragmented.

  • An SSD has no moving parts / data can be accessed equally fast wherever it is stored, so there is no speed benefit (1).
  • Defragmenting causes many extra writes, which reduces the SSD's lifespan (1).

A sales manager carries a laptop containing customer details. Explain how two different utility programs could help them.

  • Encryption software (1) so customer data can't be read if the laptop is lost/stolen (1).
  • Compression software (1) so large files take less space / can be emailed to the office quickly (1). Accept defragmentation with explanation if HDD.
