SECTION A (50 marks)

Define the term 'abstraction' and give an example.

Spec 2.1.1

  • Removing unnecessary detail to focus on what's important (1).
  • Any valid example, e.g. a map shows roads but not individual buildings (1).

Explain one benefit of decomposition when writing a large program.

Spec 2.1.1

  • Each smaller part is easier to solve/code/test (1) and parts can be given to different programmers so it's finished sooner / parts can be reused (1).

A program calculates the cost of a taxi journey from the distance travelled and the time of day. Identify the inputs, a process and the output.

Spec 2.1.2

  • Inputs: distance and time of day (1).
  • Process: e.g. multiply distance by the rate for that time / add a night surcharge (1).
  • Output: cost of the journey (1).

Complete a trace table for this algorithm and give its output.

count = 0
total = 0
for i = 3 to 9 step 3
    total = total + i
    count = count + 1
next i
print(total / count)

Spec 2.1.2

  • i takes the values 3, 6, 9 (1).
  • total: 3, 9, 18 (1).
  • count: 1, 2, 3 (1).
  • Output 6 (1).

A bubble sort is used on the list 6, 2, 8, 3, 5. Show the list after each of the first two passes, and state how the algorithm knows the list is sorted.

Spec 2.1.3

  • After pass 1: 2, 6, 3, 5, 8 (1).
  • After pass 2: 2, 3, 5, 6, 8 (1).
  • A pass is made with no swaps (1).

Explain why a binary search can't be used on the list 7, 3, 9, 1.

Spec 2.1.3

  • The list isn't sorted (1).
  • Binary search discards half the list based on whether the target is bigger or smaller than the middle item, which only works if the data is in order (1).

Describe how a merge sort would sort the list 8, 4, 6, 1.

Spec 2.1.3

  • Split into 8, 4 and 6, 1 (1).
  • Split again into single items 8 | 4 | 6 | 1 (1).
  • Merge pairs in order: 4, 8 and 1, 6 (1).
  • Merge, comparing the first item of each list, to give 1, 4, 6, 8 (1).

Spec 2.2.2

Give the result of: (i) 47 MOD 6 (ii) 47 DIV 6

Spec 2.2.1

  • (i) 5 (1) (ii) 7 (1).

Explain why casting is needed in the line age = int(input("Enter age")).

Spec 2.2.2

  • input returns a string (1) which must be converted to an integer so calculations/comparisons can be done with the age (1).

The club's database has a table called Members with the fields MemberID, Name, Age and Level. Write an SQL query to show the name and age of every member whose level is "Gold".

Spec 2.2.3

  • SELECT Name, Age (1)
  • FROM Members (1)
  • WHERE Level = "Gold" (1)

Describe the difference between a function and a procedure.

Spec 2.2.3

  • A function returns a value to where it was called (1); a procedure does not return a value, it just carries out a task (1).

Users of a website must choose a username that is 6 to 15 characters long. Describe three validation checks that could be used on the username.

Spec 2.3.1

  • Any three: presence check, something has been entered; length check, 6–15 characters; format/type check, e.g. only letters and digits / no spaces; lookup check that it isn't already taken.

A program accepts ages from 16 to 65 inclusive. Give an example of normal, boundary, invalid and erroneous test data for this program.

Spec 2.3.2

  • Normal: 17–64, e.g. 30 (1).
  • Boundary: 16 or 65 (1).
  • Invalid: e.g. 15, 66, 0 (1).
  • Erroneous: e.g. "thirty", 20.5 (1).

Give two ways a programmer can make their code easier to maintain.

Spec 2.3.1

  • Any two: comments; meaningful variable names; indentation; sub programs; constants.

Complete the truth table for P = (A OR B) AND NOT C. List the 8 rows in binary order of A, B, C.

Spec 2.4.1

  • P column for ABC = 000 to 111: 0, 0, 1, 0, 1, 0, 1, 0. One mark for each correct pair of rows.

A heater (H) turns on when it is cold (C) and either someone is at home (P) or frost protection is switched on (F). Write a Boolean expression for H.

Spec 2.4.1

  • H = C AND (P OR F). 1 for C AND ..., 1 for (P OR F) with brackets.

Explain why a programmer might use an interpreter rather than a compiler while they are still developing a program.

Spec 2.5.1

  • An interpreter stops at the first error and shows the line (1) so errors are quicker to find and fix / the program can be run without compiling it all each time (1).

SECTION B (30 marks)

Answer code questions in OCR Exam Reference Language or a high-level programming language.

SCENARIO: STEPUP FITNESS CLUB

StepUp is a fitness club. Its app records how many steps each member walks every day. Members earn an award at the end of each week based on their total steps.

Write code that asks a member for their name and then outputs "Welcome, " followed by their name.

Spec 2.2.1

  • Input name stored in a variable (1).
  • Output "Welcome, " concatenated with the name (1).

Write a program that asks the member to enter their step count for each of the 7 days of the week, stores them in an array called steps, then outputs the total and the average for the week.

Spec 2.2.1, 2.2.3

  • Array declared/used for 7 values (1).
  • Loop that runs 7 times (1).
  • Input cast to integer and stored in steps[i] (1).
  • Total calculated (1).
  • Total and average (total / 7) output (1).

Refine your program so that each step count must be between 0 and 50,000 inclusive. If it isn't, the member is told it's invalid and asked to enter it again.

Spec 2.3.1

  • Condition-controlled loop around the input (1).
  • Correct condition: < 0 OR > 50000 (1).
  • Error message output (1).
  • Input repeated until valid, then stored (1).

Complete a test plan for your validation with three tests: one normal, one boundary and one erroneous. Give the test data and the expected result for each.

Spec 2.3.2

  • Normal, e.g. 8000 → accepted (1).
  • Boundary: 0 or 50000 → accepted (1).
  • Erroneous, e.g. "lots" or 12.5 → rejected/error message (1).

Write a function award(total) that returns "Gold" if the weekly total is 70,000 or more, "Silver" if it is 50,000 or more, and "Bronze" otherwise.

Spec 2.2.3

  • Function header with parameter total (1).
  • Checks >= 70000 first and returns "Gold" (1).
  • elseif >= 50000 returns "Silver" (1).
  • else returns "Bronze" (1).

Write code that adds a line to the end of a text file called results.txt containing the member's name and weekly total, separated by a comma.

Spec 2.2.3

  • Opens results.txt (in append mode in Python) (1).
  • Writes name + "," + str(total) (1).
  • Closes the file (1).

The club stores every member's steps in a 2D array allSteps[member, day], with days 0 to 6. Write code to output the total steps for member 5.

Spec 2.2.3

  • Loop through days 0 to 6 (1).
  • Add allSteps[5, day] to a total initialised to 0 (1).
  • Output the total after the loop (1).

This algorithm should output the highest daily step count in the array steps. It contains three errors. Identify the line number of each error and give the corrected line.

01 highest = 0
02 for i = 0 to 6
03     if steps[i] < highest then
04         highest = steps[i]
05     endif
06 next
07 print("Highest: " + highest)

Spec 2.1.2, 2.3.2

  • Line 03 (1): should be if steps[i] > highest then (1).
  • Line 06 (1): should be next i (1).
  • Line 07 (1): highest must be cast to a string: print("Highest: " + str(highest)) (1).
