1.4.1 Threats to computer systems and networks

Malware

Malware (malicious software) is any software written to harm a computer system, steal data or gain unauthorised access.

TypeHow it works
VirusAttaches itself to a file or program. Spreads when the infected file is run or copied. Deletes or corrupts files.
WormReplicates itself and spreads across a network on its own, without the user doing anything. Uses up bandwidth and resources.
TrojanDisguised as legitimate, useful software. Once installed, it opens a 'back door' or does damage.
RansomwareEncrypts the victim's files and demands payment for the key.
SpywareSecretly records what the user does, e.g. keystrokes (a keylogger), and sends it to the attacker to steal passwords.

Social engineering

Social engineering means tricking people into giving away information or access. People are the weak point in a secure system: strong technical protection is useless if a user tells an attacker their password, clicks a malicious link or holds the door open.

MethodWhat happens
PhishingFake emails or messages that look like they're from a trusted organisation, e.g. a bank, asking the user to click a link and enter personal details on a fake website.
Blagging (pretexting)Inventing a believable scenario to persuade someone to give out information, e.g. phoning a help desk pretending to be a manager who has forgotten their password.
ShoulderingWatching someone enter a PIN or password over their shoulder.

Signs of phishing: generic greeting ("Dear customer"), urgency ("Your account will close in 24 hours"), spelling mistakes, a sender address or link that doesn't match the real organisation, a request for personal details.

Other attacks

AttackHow it worksEffect
Brute-force attackSoftware tries every possible password combination (or a list of common passwords) until one works.Unauthorised access to accounts.
Denial of service (DoS)Floods a server with so many requests that it can't respond to genuine users. A distributed DoS (DDoS) uses thousands of infected computers (a botnet) at once.Website or service goes offline; lost sales and reputation.
Data interception and theftData packets travelling over a network are captured (e.g. with packet-sniffing software on public Wi-Fi) and read.Passwords, personal and financial data stolen.
SQL injectionThe attacker types SQL code into an input box on a website. If the input isn't checked, the code becomes part of the database query and runs.The attacker can view, change or delete data in the database.

How SQL injection works

The website builds a query by joining the user's input onto some SQL. Look at what happens when the "username" contains SQL:

def build_query(username):
    return "SELECT * FROM users WHERE username = '" + username + "'"

print(build_query("amira"))
print(build_query("' OR '1'='1"))

SELECT * FROM users WHERE username = 'amira'
SELECT * FROM users WHERE username = '' OR '1'='1'

In the second query, '1'='1' is always true, so the database returns every user. Prevention: validate inputs (e.g. reject quote marks), and use parameterised queries so input is always treated as data, never as code.

How long does brute force take?

Each extra character, and each extra type of character, multiplies the number of passwords an attacker must try. This assumes a billion guesses per second.

guesses_per_second = 1_000_000_000
for name, size in [("digits only", 10), ("lowercase letters", 26),
                   ("upper, lower and digits", 62), ("any keyboard character", 94)]:
    total = size ** 8
    seconds = total / guesses_per_second
    print(f"8 characters, {name}: {total:,} options, {seconds:,.0f} seconds")

8 characters, digits only: 100,000,000 options, 0 seconds
8 characters, lowercase letters: 208,827,064,576 options, 209 seconds
8 characters, upper, lower and digits: 218,340,105,584,896 options, 218,340 seconds
8 characters, any keyboard character: 6,095,689,385,410,816 options, 6,095,689 seconds
Malware
Malicious software designed to damage a system, steal data or gain unauthorised access.
Virus
Malware that attaches to a file or program and spreads when the infected file is run or copied.
Worm
Malware that replicates itself and spreads across a network without user action.
Trojan
Malware disguised as legitimate software.
Ransomware
Malware that encrypts a victim's files and demands payment for the decryption key.
Spyware
Malware that secretly monitors a user's activity, e.g. recording keystrokes, and sends it to the attacker.
Social engineering
Manipulating people into revealing confidential information or giving access.
Phishing
Fake emails or messages pretending to be from a trusted organisation to trick people into giving personal details.
Brute-force attack
Trying every possible combination of characters until the correct password is found.
Denial of service attack
Flooding a server with requests so it can't respond to genuine users.
Data interception
Capturing data packets as they travel across a network so they can be read.
SQL injection
Entering SQL code into an input box so it runs as part of a database query, giving access to the data.

1.4.2 Identifying and preventing vulnerabilities

MethodHow it worksProtects against
Penetration testingThe organisation pays (authorised) experts to attack its own system, the way a real hacker would, to find weaknesses so they can be fixed before they are exploited.Finding any vulnerability, e.g. SQL injection, weak passwords
Anti-malware softwareScans files and compares them with a database of known malware signatures; quarantines or deletes threats; monitors for suspicious behaviour. Must be updated regularly.Viruses, worms, trojans, spyware, ransomware
FirewallHardware or software that monitors incoming and outgoing network traffic and blocks anything that doesn't meet a set of rules, e.g. blocked ports or addresses.Unauthorised access, hacking, some DoS and malware
User access levelsEach user is given access only to the files and functions they need for their job. Admins can install software; most users can't.Insiders accessing or deleting data they shouldn't; limits damage if an account is compromised
PasswordsAuthenticate users. Strong passwords are long, mix character types, aren't words; changed if compromised; locked out after several failed tries; use two-factor authentication.Brute-force attacks, unauthorised access
EncryptionScrambles data using a key so it can't be understood without the key.Data interception and theft (data is useless if stolen)
Physical securityLocks, keycards, CCTV, security guards, biometric entry to server rooms.Theft of hardware, unauthorised physical access

Match the threat to the best protection

Customers connect to a hotel's public Wi-Fi to check their bank accounts.

An attacker's program tries thousands of passwords a second on the school login page.

Staff keep clicking links in emails pretending to be from IT support.

A receptionist can open and change every patient's medical records.

Laptops keep disappearing from an office after hours.

A bank wants to find weaknesses in its new app before criminals do.

An employee downloads a "free game" that turns out to be a trojan.

★ EXAM TIP: BE SPECIFIC

  • "Use a firewall" scores less than "a firewall checks incoming traffic against rules and blocks unauthorised access to the network".
  • Match the protection to the threat in the question. Encryption doesn't stop malware; anti-malware doesn't stop phishing calls.
  • For social engineering the best answer is usually training staff to spot it, plus a policy (e.g. IT never asks for your password).
Penetration testing
Authorised simulated attacks on a system to find vulnerabilities so they can be fixed.
Anti-malware
Software that scans for, detects and removes or quarantines malware.
Firewall
Hardware or software that monitors network traffic and blocks traffic that doesn't meet set rules.
User access levels
Controls on which files and functions each user can access, based on what they need.
Physical security
Measures such as locks, keycards and CCTV that stop unauthorised people reaching hardware.

Exam-style questions

Allow about 30 minutes. Answer each question before you look at its mark scheme.

Describe what is meant by a brute-force attack.

  • Repeatedly trying different passwords/combinations (1) until the correct one is found, often using automated software (1).

Explain why people are often described as the weak point in a secure system.

  • People can be tricked/manipulated, e.g. by phishing or blagging (1) into giving away passwords or access, which gets round technical security (1). Accept: careless behaviour, e.g. weak passwords, leaving computers logged in.

Describe two features of an email that might show it is a phishing email.

  • Any two features, each with a description, 2 marks each: generic greeting, e.g. "Dear customer", because the sender doesn't know your name; urgent/threatening tone to rush you; spelling/grammar mistakes; sender address doesn't match the organisation; link to a fake website; asks for personal details/passwords.

Describe what a denial of service attack is.

  • A server/website is flooded with requests/traffic (1) so it can't respond to genuine users / goes offline (1).

An online shop has a search box. Explain how an SQL injection attack could be carried out, and one way to prevent it.

  • The attacker types SQL code into the search box (1).
  • If the input isn't validated, the code is run as part of the database query, letting them view/change/delete data (1).
  • Prevention: validate/sanitise input / use parameterised queries / restrict database access levels (1).

Explain the difference between a virus and a worm.

  • A virus attaches to a file and needs a user to run/copy the file to spread (1).
  • A worm replicates and spreads across a network by itself (1).

Describe the purpose of penetration testing.

  • Authorised people attempt to attack/hack the system (1) to find vulnerabilities so they can be fixed before they are exploited (1).

Explain how a firewall helps to protect a network.

  • It monitors incoming and outgoing traffic (1) and blocks traffic that doesn't meet its rules / unauthorised access (1).

A doctors' surgery stores patient records on its network. Staff use computers in consulting rooms and at reception. Explain three methods the surgery could use to keep the patient records secure.

  • Any three methods, each explained in the context, 2 marks each, e.g.: user access levels (1) so receptionists can see appointments but not medical notes (1); strong passwords with lockout (1) so a stolen login or brute force can't be used to view records (1); encryption (1) so records are unreadable if intercepted or a laptop is stolen (1); firewall (1) to block hackers from the Internet (1); anti-malware (1) to stop ransomware encrypting records (1); physical security, e.g. locked server room (1) so equipment can't be stolen (1); staff training (1) so staff don't fall for phishing (1).
