★ EXAM TIP: MOD AND DIV

  • MOD 2 tells you if a number is even (remainder 0) or odd (remainder 1).
  • Convert 135 minutes to hours and minutes: 135 DIV 60 = 2 hours, 135 MOD 60 = 15 minutes.
  • = assigns a value; == compares two values.

In ERL, substring(start, length) takes a start position and a number of characters. In Python, word[3:6] takes a start and an end position (the end isn't included). Joining strings with + is called concatenation.

File handling

Files let a program keep data after it closes, e.g. high scores or settings. The four basic operations are open, read, write and close. Always close a file, so changes are saved and other programs can use it.

ERL

newFile("scores.txt")
myFile = open("scores.txt")
myFile.writeLine("Ali,12")
myFile.writeLine("Bea,15")
myFile.close()

myFile = open("scores.txt")
while NOT myFile.endOfFile()
    line = myFile.readLine()
    print(line)
endwhile
myFile.close()

PY

file = open("scores.txt", "w")
file.write("Ali,12\n")
file.write("Bea,15\n")
file.close()

file = open("scores.txt", "r")
for line in file:
    parts = line.strip().split(",")
    print(parts[0], "scored", parts[1])
file.close()

Ali scored 12
Bea scored 15

In Python, mode "w" creates a new file (or overwrites one), "a" appends to the end, and "r" reads.

Records

A record groups related data about one item. Each piece of data is a field, and fields can be different data types. A collection of records with the same fields is a table (in a database) or a file.

2.2.3 Sub programs and random numbers

A sub program is a named block of code that does a specific task and can be called (used) whenever it is needed.

FunctionProcedure
Returns a value?Yes: always returns a value to where it was calledNo: just carries out a task
ExampleCalculate and return the area of a roomPrint a banner

ERL

function area(width, height)
    return width * height
endfunction

procedure showBanner(message)
    print("** " + message + " **")
endprocedure

showBanner("Room planner")
print("Area: " + str(area(4, 3)))

PY

def area(width, height):         # function: returns a value
    return width * height

def show_banner(message):        # procedure: does a job
    print("** " + message + " **")

show_banner("Room planner")
print("Area:", area(4, 3))

** Room planner **
Area: 12

Parameters are the variables listed in the sub program's definition (width, height). Arguments are the actual values passed in when it is called (4, 3).

Local and global variables

Local variableGlobal variable
Declared inside a sub program; only exists while it runs; can't be used elsewhereDeclared in the main program; can be used anywhere in the program
Saves memory; the same name can be used in different sub programs without clashing; sub programs are easier to test and reuseUseful for values the whole program needs, but can be changed by mistake anywhere, making bugs hard to find
count = 0                 # global

def add_one():
    global count
    count = count + 1

def double(n):
    result = n * 2        # local: only exists inside double
    return result

add_one()
add_one()
print(count, double(count))

2 4

Why use sub programs?

  • Code is written once and reused, so programs are shorter.
  • Each sub program can be tested separately.
  • Programs are easier to read and maintain: fix a bug once and it's fixed everywhere.
  • Different programmers can work on different sub programs.
