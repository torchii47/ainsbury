This is the whole GCSE Computer Science revision guide as a website you can use on any device. Every page has notes, tables, worked examples and tested Python code, plus tools to test yourself as you go.

Written for OCR GCSE (9–1) Computer Science (J277): Paper 1 Computer systems (J277/01) and Paper 2 Computational thinking, algorithms and programming (J277/02). Code is shown in OCR Exam Reference Language and in Python.

This guide is an independent teaching resource. It is not produced, checked or endorsed by OCR or the Joint Council for Qualifications (JCQ). The mock papers are practice papers written in the style of the live assessments. All Python code in this guide has been run and tested in Python 3.10 or later. Free for students and teachers to use. Not for resale.

How to use this guide

This guide covers everything in the J277 specification for Paper 1 and Paper 2. Each topic page follows the same pattern, so you always know where to look.

FeatureWhat it is forOnline, you can...
Topic bannerThe coloured banner listing what the topic covers and how it links to others.Use the On this page list to jump to any section.
Spec checklistRate yourself on every specification point: Secure, Unsure or Revise. Start with your 'Revise' topics.Tick a rating. It's saved, and your 'Revise' points appear on this home page.
NotesNotes for every point of the specification, with tables, worked examples and code.Predict each code output before you reveal it. Press ▶ Run to run the Python yourself.
Quick recallKey definitions for the topic.Cover the definitions, then click each one to check you knew it.
Knowledge organiserOne page of the key facts for the topic. Use it for quick recall before an exam.Use Test me to blur every fact, then reveal them one at a time. Flashcards are built from every definition on the page.
Quiz meQuick random questions from the GCSE question bank.Pick a question type, answer, then check. Your score is saved.
Exam-style questionsPractice questions with marks, in the style of the real papers.Type your answer, reveal the mark scheme, then give yourself a mark to see your score.
Mock papers (Part C)Two full 80-mark papers. Sit them timed.Use the built-in 1 h 30 min timer. Mark schemes unlock when you finish.
GlossaryEvery key term defined in one A–Z list.Filter the glossary, practise with flashcards, or search the whole guide.
