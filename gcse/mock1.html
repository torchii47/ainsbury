Question 1: Systems architecture

Zainab is buying a laptop for playing games and editing videos.

Describe the purpose of cache in the laptop's CPU.

Spec 1.1.1

  • Small, fast memory in/near the CPU (1) that stores frequently used data/instructions so the CPU doesn't have to wait for slower RAM (1).

Describe what happens during the decode and execute stages of the fetch-execute cycle.

Spec 1.1.1

  • Decode: the control unit works out what the instruction means/what needs to be done (1).
  • Execute: the instruction is carried out, e.g. a calculation by the ALU with the result in the accumulator / data loaded or stored (1).

State the name of the register that holds the address of the next instruction to be fetched.

Spec 1.1.1

  • Program counter / PC (1).

Laptop A has a quad-core 2.8 GHz CPU. Laptop B has a dual-core 3.4 GHz CPU. Explain which laptop is likely to be better for Zainab's video editing.

Spec 1.1.2

  • Laptop A has more cores (1) so it can process more instructions at the same time/in parallel (1).
  • Video editing software can split work across several cores, so A is likely to be faster overall (1).
  • Laptop B carries out more cycles per second per core (1), which helps single-threaded tasks, but this is unlikely to outweigh two extra cores. (Max 4; accept a reasoned case for B if justified.)

Zainab's washing machine contains an embedded system. Describe three characteristics of an embedded system.

Spec 1.1.3

  • Any three, 1 each: dedicated to one task/function; part of a larger device; small; low power; cheap to make; reliable; firmware in ROM; limited/no user interface; hard to upgrade.

(Total for Question 1 = 12 marks)

Question 2: Memory and storage

Give two differences between RAM and ROM.

Spec 1.2.1

  • Any two: RAM is volatile / ROM is non-volatile; RAM is read/write / ROM is read only; RAM holds programs and data in use / ROM holds the boot-up instructions; RAM is usually larger.

Explain why a computer may need virtual memory.

Spec 1.2.1

  • When RAM is full (1), part of secondary storage is used as extra RAM so more programs can stay open / the computer doesn't crash (1).

A wildlife photographer works outdoors in remote places. Recommend a type of secondary storage for her camera and justify your choice.

Spec 1.2.2

  • Solid state / SD card / flash (1).
  • Justification, any two: durable / no moving parts, so won't break if dropped (1); small and light, so portable (1); low power, so the camera battery lasts longer (1); fast, so photos are saved quickly (1).

Convert the denary number 201 to 8-bit binary.

Spec 1.2.4

  • 11001001 (1).

Convert the hexadecimal number A7 to denary.

Spec 1.2.4

  • 167 (1).

Convert the binary number 01011110 to hexadecimal. Show your working.

Spec 1.2.4

  • Nibbles 0101 = 5 and 1110 = 14/E (1). Answer 5E (1).

Add the binary numbers 01101100 and 01010111. Give your answer as an 8-bit binary number.

Spec 1.2.4

  • 11000011 (2). 1 mark for working with correct carries but one bit wrong.

The binary number 01101000 has a right shift of 3 places applied. Give the result and state the effect on the number.

Spec 1.2.4

  • 00001101 (1).
  • It is divided by 8 (104 → 13) (1).

A 2-minute sound clip is recorded with a sample rate of 8,000 Hz and a bit depth of 8 bits. Calculate the file size in kilobytes. Show your working.

Spec 1.2.3

  • 8,000 × 8 × 120 = 7,680,000 bits (1).
  • ÷ 8 = 960,000 bytes (1).
  • ÷ 1,000 = 960 KB (1). (Accept 937.5 KB using 1,024.)

Explain the effect of increasing the colour depth of an image.

Spec 1.2.4

  • More bits per pixel, so more colours can be represented / better quality (1).
  • File size increases (1).

(Total for Question 2 = 20 marks)

Question 3: Networks

An accountancy firm has 25 staff in one office building.

The firm's network is a LAN. Explain why it is a LAN and not a WAN.

Spec 1.3.1

  • It covers a small geographical area / one building (1).
  • The hardware is owned and managed by the firm (1).

The office uses a star topology. Explain one advantage and one disadvantage of a star topology for the firm.

Spec 1.3.1

  • Advantage (1) with explanation (1): e.g. if one cable/computer fails, the others still work, so other staff can carry on working.
  • Disadvantage (1) with explanation (1): e.g. if the central switch fails, the whole network fails, so no one can access files.

State the purpose of a switch and of a router in the firm's network.

Spec 1.3.1

  • Switch: connects devices on the LAN and sends data to the correct device (using MAC addresses) (1).
  • Router: connects the LAN to other networks/the Internet and routes packets (using IP addresses) (1).

Describe how DNS is used when a member of staff visits www.example.co.uk.

Spec 1.3.1

  • The domain name is sent to a DNS server (1).
  • The DNS server looks up/finds the matching IP address (or asks another DNS server) (1).
  • The IP address is returned and used to request the page from the web server (1).

Staff read their email on their desktop computer and their phone. Explain why the firm should use IMAP rather than POP.

Spec 1.3.2

  • IMAP keeps emails on the server (1) so they are synchronised/available on both devices; POP downloads them to one device (1).

Give two benefits of using layers in networking.

Spec 1.3.2

  • Any two: each layer can be changed without affecting others; breaks a complex system into manageable parts; manufacturers can make compatible products for one layer; easier to find and fix problems.

(Total for Question 3 = 15 marks)

Question 4: Network security

Describe what is meant by phishing.

Spec 1.4.1

  • Fake emails/messages pretending to be from a trusted organisation (1) to trick people into giving personal details/clicking a malicious link (1).

Describe how an SQL injection attack works.

Spec 1.4.1

  • SQL code is typed into an input box on a website (1) and, if not validated, runs as part of the database query, giving access to/changing data (1).

The accountancy firm stores clients' financial records on its network. Explain three methods the firm could use to protect the records.

Spec 1.4.2

  • Three methods, each identified (1) and explained in context (1), e.g.: user access levels so only the accountant for a client can open their records; strong passwords/lockout to stop brute force; encryption so stolen or intercepted records can't be read; firewall to block unauthorised access from the Internet; anti-malware to detect ransomware/spyware; staff training to recognise phishing; physical security such as a locked server room; penetration testing to find weaknesses.

(Total for Question 4 = 10 marks)

Question 5: Systems software

Describe how the operating system manages memory.

Spec 1.5.1

  • Any two: moves programs/data into and out of RAM; allocates memory to each program; stops programs overwriting each other's memory; uses virtual memory when RAM is full.

A new printer is connected to a computer. Explain why a device driver is needed.

Spec 1.5.1

  • The driver is software that lets the OS communicate with the printer (1) by translating the OS's general instructions into ones that specific printer understands (1).

Explain how defragmentation software can improve the performance of a computer with a hard disk drive.

Spec 1.5.2

  • Moves the fragments of each file so they are stored together/contiguously (1).
  • Groups free space together (1).
  • The read/write head moves less, so files are read faster (1).

State one other type of utility software.

Spec 1.5.2

  • Encryption software / compression software (accept backup, anti-malware) (1).

(Total for Question 5 = 8 marks)

Question 6: Legislation and licences

State two offences under the Computer Misuse Act 1990.

Spec 1.6.1

  • Any two: unauthorised access to computer material; unauthorised access with intent to commit/facilitate further offences; unauthorised acts with intent to impair the operation of a computer (e.g. spreading malware).

The firm holds personal data about its clients. Describe three ways the Data Protection Act 2018 affects how it handles this data.

Spec 1.6.1

  • Any three: must be used fairly, lawfully and transparently / tell clients what it's used for; only used for the stated purpose; only collect what is needed; keep it accurate and up to date; don't keep it longer than necessary; keep it secure; clients can request to see their data.

A small charity is choosing office software. Explain one reason why it might choose open source software.

Spec 1.6.1

  • It is usually free (1) so the charity can spend its limited money on its work (1). Accept: can be modified to meet its needs (1) by a volunteer programmer (1).

(Total for Question 6 = 7 marks)

Question 7: Extended response

A hospital plans to use artificial intelligence (AI) software to examine patients' X-ray scans and suggest a diagnosis to doctors.

Discuss the ethical, legal and privacy issues of this plan. In your answer you might consider: the impact on patients; the impact on hospital staff; how patient data is used and stored.

Spec 1.6.1

Indicative content:

  • Ethical, positive: faster diagnosis and shorter waits; may spot problems humans miss; frees doctors' time for patients.
  • Ethical, negative: AI can be biased if trained on data that under-represents some groups, leading to unfair outcomes; who is responsible for a wrong diagnosis; patients may want a human decision; staff may worry about deskilling or jobs.
  • Legal: scans are personal (health) data under the Data Protection Act 2018: lawful basis, patients told how data is used, kept secure, not kept longer than needed; liability if the AI is wrong; data sent to an AI company may leave the hospital.
  • Privacy: large databases of scans are a target for hackers; data could be shared with or sold to third parties; patients may not consent to their scans being used to train the AI; need for encryption and access levels.
  • Conclusion: e.g. beneficial if doctors make the final decision, the AI is checked for bias, and data is protected.

(Total for Question 7 = 8 marks)
