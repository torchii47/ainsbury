Flashcards

Built from the terms shown below, so filter first to practise one topic.

0–9

2D array
An array of arrays, like a table, where each element is found using two indexes.

A

Abstraction
Removing unnecessary detail from a problem to focus on the important parts.
Accumulator
Register that holds the results of calculations carried out by the ALU.
Algorithm
A sequence of steps that can be followed to complete a task or solve a problem.
Algorithmic thinking
Identifying the steps needed to solve a problem, in a logical order.
ALU
Arithmetic logic unit: performs arithmetic and logical operations and comparisons.
AND gate
Outputs 1 only when both inputs are 1.
Anti-malware
Software that scans for, detects and removes or quarantines malware.
Array
A data structure that stores a fixed number of values of the same data type under one name, accessed by index.
ASCII
A character set that uses 7 bits (or 8 for extended ASCII) to represent 128 (or 256) characters, mainly English.
Assembler
A translator that converts assembly language into machine code.
Assembly language
A low-level language that uses short mnemonics, each translating to one machine code instruction.
Assignment
Giving a value to a variable or constant.
Authentication
Confirming the identity of a user, e.g. with a username and password.

B

Bandwidth
The amount of data that can be transmitted over a network in a given time.
Binary
Base 2: a number system using only the digits 0 and 1.
Binary search
A search of a sorted list that repeatedly checks the middle item and discards the half that can't contain the target.
Binary shift
Moving every bit left (multiply by 2 per place) or right (divide by 2 per place).
Bit
A single binary digit, 1 or 0: the smallest unit of data.
Bit depth
The number of bits used to store each sound sample (also called sample resolution).
Boolean
A data type with only two possible values: True or False.
Boolean expression
A statement using AND, OR and NOT, e.g. P = (A AND B) OR NOT C, that is either True or False.
Boundary data
Valid test data at the edge of the allowed range.
Breakpoint
A marker that pauses a program at a chosen line so its state can be inspected.
Brute-force attack
Trying every possible combination of characters until the correct password is found.
Bubble sort
A sort that repeatedly compares adjacent pairs and swaps them if in the wrong order, until a pass is made with no swaps.
Byte
8 bits.

C

Cache
Small, very fast memory in or near the CPU that stores frequently used instructions and data.
Cache size
The amount of data and instructions the cache can store; larger means fewer slow trips to RAM.
Casting
Converting a value from one data type to another, e.g. str to int.
Character
A data type for a single letter, digit or symbol.
Character set
A defined list of characters recognised by a computer, each with a unique binary code.
Client-server network
A network in which servers provide services and resources that clients request.
Clock speed
The number of fetch-execute cycles a CPU carries out per second, measured in hertz (e.g. GHz).
Colour depth
The number of bits used to represent the colour of each pixel.
Command-line interface
A text-based interface where the user types commands.
Comment
A note in code that explains it to people reading it and is ignored when the program runs.
Compiler
A translator that converts the whole program into machine code at once, producing an executable file.
Compression
Reducing the size of a file so it takes less storage space and transmits faster.
Compression software
A utility that reduces the size of files.
Computer Misuse Act 1990
UK law making unauthorised access to computer material, and unauthorised acts that impair computers, illegal.
Concatenation
Joining two or more strings together.
Condition-controlled loop
A loop that repeats until (or while) a condition is met, e.g. while or do until.
Constant
A named value that cannot change while the program runs.
Control unit
Decodes instructions and sends control signals to coordinate the movement of data and the fetch-execute cycle.
Copyright, Designs and Patents Act 1988
UK law protecting original work, such as software, music and images, from being copied or shared without permission.
Core
An independent processing unit within a CPU that can carry out its own fetch-execute cycle.
Count-controlled loop
A loop that repeats a fixed number of times, e.g. a for loop.
CPU
Central processing unit: the component that processes data and instructions by carrying out the fetch-execute cycle.
Cultural issue
How technology changes the way people live, work, communicate and behave.

D

Data interception
Capturing data packets as they travel across a network so they can be read.
Data Protection Act 2018
UK law controlling how organisations collect, store and use personal data, based on the GDPR.
Data subject
The person that personal data is about.
Decomposition
Breaking a complex problem down into smaller, more manageable sub-problems.
Defensive design
Designing a program so it keeps working correctly even when it is misused or given unexpected input.
Defragmentation
Reorganising a hard disk so the parts of each file are stored together and free space is grouped, making access faster.
Denary
Base 10: the number system using the digits 0–9.
Denial of service attack
Flooding a server with requests so it can't respond to genuine users.
Device driver
Software that lets the operating system communicate with a specific hardware device.
Digital divide
The gap between people who have access to digital technology and the Internet, and the skills to use it, and those who don't.
DIV
Integer division: gives the whole number part of a division, e.g. 17 DIV 5 = 3.
DNS
Domain Name System: translates domain names (e.g. www.bbc.co.uk) into IP addresses.
Durability
How well a storage device withstands physical damage and wear.

E

Embedded system
A computer system built into a larger device to carry out a dedicated function.
Encryption
Scrambling data using a key so that it can't be understood if intercepted.
Encryption software
A utility that scrambles files or drives so they can only be read with the correct key.
Erroneous data
Test data of the wrong data type that should be rejected.
Error diagnostics
IDE tools that detect errors and report them, usually with a line number and a description.
Ethernet
A standard for wired network connections.
Ethical issue
A question of whether something is morally right or wrong, fair or unfair.
E-waste
Discarded electronic devices, which can release toxic substances if not disposed of properly.

F

Fetch-execute cycle
The repeated process in which the CPU fetches an instruction from memory, decodes it and executes it.
Field
One item of data in a record, e.g. Name or Age.
File handling
Opening, reading from, writing to and closing files so data is kept after the program ends.
File management
The OS organising files into folders and letting users create, move, copy, rename and delete them.
Final testing
Testing the whole program at the end of development to check it meets the requirements (also called terminal testing).
Firewall
Hardware or software that monitors network traffic and blocks traffic that doesn't meet set rules.
Flowchart
A diagram that represents an algorithm using standard symbols connected by arrows.
Format check
A validation check that data follows a set pattern, e.g. a date as DD/MM/YYYY.
Function
A sub program that returns a value.

G

General-purpose computer
A computer, like a PC or smartphone, that can run many different programs for many different tasks.
Global variable
A variable that can be accessed from anywhere in the program.
GUI
Graphical user interface: lets users interact using windows, icons, menus and a pointer.

H

Hexadecimal
Base 16: uses the digits 0–9 and the letters A–F; each hex digit represents one nibble.
High-level language
A programming language with English-like statements that is portable and easy to read, e.g. Python.
Hosting
Storing websites or files on a server so they can be accessed over the Internet.
HTTPS
The secure, encrypted version of HTTP, used to transfer web pages.

I

IDE
Integrated Development Environment: software providing tools to write, run, test and debug programs.
IMAP
An email protocol that keeps mail on the server so it can be accessed from several devices.
Index
The position of an element in an array or string, starting at 0.
Insertion sort
A sort that takes each item in turn and inserts it into the correct position in the already sorted part of the list.
Integer
A data type for whole numbers.
Intellectual property
Original creative work or ideas that belong to the person or organisation that created them.
Internet
A worldwide collection of interconnected computer networks.
Interpreter
A translator that translates and executes a program one line at a time.
Invalid data
Test data of the correct type that is outside the allowed range and should be rejected.
IP address
An address given to a device on a network, used to route data between networks.
Iteration
Repeating a set of instructions, using a loop.
Iterative testing
Testing each part of a program repeatedly during development, fixing errors as they are found.

L

LAN
Local area network: a network over a small geographical area, using hardware owned by the organisation.
Layer
A division of network functionality with its own job and protocols, which works independently of the other layers.
Length check
A validation check that data has an allowed number of characters.
Linear search
A search that checks each item in turn, from the start, until the item is found or the end is reached.
Local variable
A variable that only exists inside the sub program where it is declared.
Logic diagram
A diagram showing how logic gates are connected to form a circuit.
Logic error
An error that lets the program run but produces an incorrect result.
Logic gate
An electronic circuit that takes one or more binary inputs and produces one binary output.
Lossless compression
Compression that reduces file size without losing any data, so the original can be restored exactly.
Lossy compression
Compression that permanently removes some data, so the original file can't be restored exactly.
Low-level language
A language close to machine code, such as assembly or machine code, written for a specific CPU.

M

MAC address
A unique 48-bit hexadecimal address assigned to a network interface controller when it is made.
Machine code
Binary instructions that the CPU can execute directly.
Magnetic storage
Storage that records data by magnetising areas of a surface, e.g. hard disk drive, tape.
Maintainability
How easy a program is to understand, fix and update.
Malware
Malicious software designed to damage a system, steal data or gain unauthorised access.
MAR
Memory address register: holds the address of the memory location about to be read from or written to.
MDR
Memory data register: holds the data or instruction just fetched from memory, or about to be written to it.
Memory management
The OS allocating RAM to programs, moving data in and out of memory and stopping programs overwriting each other.
Merge sort
A sort that splits a list into single items, then repeatedly merges pairs of sub-lists into sorted order.
Mesh topology
A network layout in which devices are connected to many (or all) other devices, giving several routes for data.
Metadata
Data about data, e.g. an image's width, height and colour depth stored in the file.
MOD
The modulus operator: gives the remainder of a division, e.g. 17 MOD 5 = 2.
Multitasking
Running several programs apparently at the same time by giving each a share of CPU time in turn.

N

Nibble
4 bits.
NIC
Network interface controller: hardware that allows a device to connect to a network.
Normal data
Typical, valid test data that the program should accept.
NOT gate
Outputs the opposite of its single input.

O

Open source software
Software whose source code is freely available for anyone to view, modify and redistribute.
Operating system
Systems software that manages the computer's hardware and software and provides a platform for applications.
Optical storage
Storage read by a laser from pits and lands on a disc, e.g. CD, DVD, Blu-ray.
OR gate
Outputs 1 when either or both inputs are 1.
Overflow
An error that occurs when the result of a calculation is too large to be stored in the number of bits available.

P

Parameter
A variable in a sub program's definition that receives a value when the sub program is called.
Pass
One complete run through the list in a bubble sort.
Peer-to-peer network
A network in which all computers have equal status and share resources directly with each other.
Penetration testing
Authorised simulated attacks on a system to find vulnerabilities so they can be fixed.
Personal data
Data that relates to a living, identifiable person.
Phishing
Fake emails or messages pretending to be from a trusted organisation to trick people into giving personal details.
Physical security
Measures such as locks, keycards and CCTV that stop unauthorised people reaching hardware.
Pixel
A single dot of colour: the smallest element of a bitmap image.
Presence check
A validation check that data has been entered.
Primary storage
Memory that the CPU can access directly, such as RAM, ROM and cache.
Procedure
A sub program that carries out a task but does not return a value.
Program counter
Register holding the address of the next instruction to be fetched.
Proprietary software
Software whose source code is kept private by the owner; users buy a licence to use it but can't modify or share it.
Protocol
A set of rules that govern how data is transmitted and how devices communicate on a network.
Pseudocode
A way of writing an algorithm using structured English-like statements, not tied to one programming language.

R

RAM
Random access memory: volatile memory that holds the operating system, programs and data currently in use.
Range check
A validation check that a value lies between set limits.
Ransomware
Malware that encrypts a victim's files and demands payment for the decryption key.
Real
A data type for numbers with a decimal part (also called float).
Record
A data structure that stores related fields, which can be different data types, about one item.
Register
A very small, very fast storage location inside the CPU that holds a single value currently being used.
Resolution
The number of pixels in an image, often given as width × height.
ROM
Read only memory: non-volatile memory that holds the start-up (boot) instructions.
Router
Sends data packets between different networks, using IP addresses.
Run-time environment
A feature that lets a program run within the IDE, showing its output and any run-time errors.

S

Sample rate
The number of samples of a sound wave taken each second, measured in hertz.
Secondary storage
Non-volatile storage used to keep data, programs and the operating system permanently.
Selection
Choosing which instructions to run based on a condition, e.g. if statements.
Sequence
Instructions carried out one after another in order.
SMTP
The protocol used to send email.
Social engineering
Manipulating people into revealing confidential information or giving access.
Solid state storage
Storage with no moving parts that uses flash memory, e.g. SSD, USB stick, SD card.
Source code
The original program written by the programmer in a programming language.
Spyware
Malware that secretly monitors a user's activity, e.g. recording keystrokes, and sends it to the attacker.
SQL
Structured Query Language: a language used to search and manage data in databases.
SQL injection
Entering SQL code into an input box so it runs as part of a database query, giving access to the data.
Stakeholder
Any person or group affected by, or with an interest in, a technology or decision.
Standards
Agreed rules for hardware and software so that products from different manufacturers work together.
Star topology
A network layout in which every device is connected to a central switch.
String
A data type for a sequence of characters.
Structure diagram
A diagram showing how a problem is decomposed into smaller sub-problems.
Sub program
A named, self-contained block of code that performs a specific task and can be called when needed.
Substring
Part of a string, taken from a given position.
Switch
Connects devices on a LAN and sends data only to the device it is addressed to, using MAC addresses.
Syntax error
An error that breaks the rules of the programming language, so the program won't run.
Syntax highlighting
An editor feature that colours different parts of the code, such as keywords and strings, to make it easier to read.

T

TCP/IP
The protocols that split data into packets, address and route them, and reassemble them in order at the destination.
Test plan
A table listing each test, its purpose, the test data, the expected result and the actual result.
The cloud
Remote servers accessed over the Internet that store data and provide software and services.
Trace table
A table used to record the values of variables as an algorithm is followed line by line.
Translator
A program that converts source code into machine code.
Trojan
Malware disguised as legitimate software.
Truth table
A table showing the output of a logic gate or circuit for every possible combination of inputs.
Type check
A validation check that data is the correct data type.

U

Unicode
A character set using more bits per character, so it can represent characters from almost every language, plus symbols and emoji.
User access levels
Controls on which files and functions each user can access, based on what they need.
User management
The OS creating user accounts and controlling each user's access rights.
Utility software
Systems software that helps maintain, optimise or protect the computer.

V

Validation
Checking that input data is sensible and meets set rules before it is processed.
Variable
A named location in memory that stores a value that can change while the program runs.
Virtual memory
Part of secondary storage used as extra RAM when RAM is full.
Virus
Malware that attaches to a file or program and spreads when the infected file is run or copied.
Volatile
Memory that loses its contents when the power is switched off.
Von Neumann architecture
A computer design in which program instructions and data are stored together in the same memory and fetched by the CPU one at a time.

W

WAN
Wide area network: a network over a large geographical area, often using third-party infrastructure.
WAP
Wireless access point: allows wireless devices to connect to a wired network.
Web server
A computer that stores web pages and sends them to clients that request them.
Worm
Malware that replicates itself and spreads across a network without user action.
