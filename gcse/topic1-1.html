1.1.1 Architecture of the CPU

The central processing unit (CPU) is the part of the computer that processes data and instructions. Its purpose is to carry out the fetch-execute cycle: fetch an instruction from memory, decode it, execute it, and repeat, billions of times a second.

Common CPU components

ComponentWhat it does
ALU (arithmetic logic unit)Carries out arithmetic (add, subtract) and logical operations (AND, OR, NOT) and comparisons (is A > B?).
CU (control unit)Decodes instructions. Sends control signals that coordinate how data moves around the CPU and between the CPU and other components. Controls the fetch-execute cycle.
CacheA small amount of very fast memory inside or very close to the CPU. Stores frequently used instructions and data so the CPU doesn't have to wait for slower RAM.
RegistersTiny, extremely fast storage locations inside the CPU, each holding one value (an address, an instruction or data) that is being used right now.
CPU
Central processing unit: the component that processes data and instructions by carrying out the fetch-execute cycle.
ALU
Arithmetic logic unit: performs arithmetic and logical operations and comparisons.
Control unit
Decodes instructions and sends control signals to coordinate the movement of data and the fetch-execute cycle.
Cache
Small, very fast memory in or near the CPU that stores frequently used instructions and data.
Register
A very small, very fast storage location inside the CPU that holds a single value currently being used.

Von Neumann architecture

In the Von Neumann architecture, program instructions and data are stored together in the same memory, in the same format (binary). The CPU fetches each instruction from memory, one at a time, and executes it. It uses four special registers:

RegisterWhat it holds
Program counter (PC)The address of the next instruction to be fetched. It is incremented during each fetch.
Memory address register (MAR)The address in memory that is about to be read from or written to.
Memory data register (MDR)The data or instruction that has just been fetched from memory, or that is about to be written to memory.
Accumulator (ACC)The result of calculations carried out by the ALU.

The fetch-execute cycle

StageWhat happens
Fetch
  1. The address in the PC is copied to the MAR.
  2. The instruction at that address is fetched from memory and stored in the MDR.
  3. The PC is incremented (add 1) so it points to the next instruction.
DecodeThe control unit decodes the instruction in the MDR to work out what it means and what needs to happen.
ExecuteThe instruction is carried out, e.g. the ALU does a calculation and stores the result in the accumulator, or data is loaded from or stored to memory (using the MAR and MDR again). Then the cycle repeats.

Try it: a tiny CPU in Python

This simulation runs a four-instruction program stored in the same memory as its data (Von Neumann). It prints the registers at the end of each cycle. It's simplified: a real LOAD would use the MAR and MDR a second time to fetch the data.

memory = ["LOAD 5", "ADD 6", "STORE 7", "HALT", "", 12, 30, 0]
pc = 0
acc = 0
running = True
while running:
    mar = pc                      # fetch: copy the PC into the MAR
    mdr = memory[mar]             # the instruction at that address goes into the MDR
    pc = pc + 1                   # the PC now points to the next instruction
    parts = mdr.split()           # decode
    opcode = parts[0]
    if opcode == "LOAD":          # execute
        acc = memory[int(parts[1])]
    elif opcode == "ADD":
        acc = acc + memory[int(parts[1])]
    elif opcode == "STORE":
        memory[int(parts[1])] = acc
    elif opcode == "HALT":
        running = False
    print("PC =", pc, "| MAR =", mar, "| MDR =", mdr, "| ACC =", acc)
print("Address 7 now holds", memory[7])

PC = 1 | MAR = 0 | MDR = LOAD 5 | ACC = 12
PC = 2 | MAR = 1 | MDR = ADD 6 | ACC = 42
PC = 3 | MAR = 2 | MDR = STORE 7 | ACC = 42
PC = 4 | MAR = 3 | MDR = HALT | ACC = 42
Address 7 now holds 42

✗ COMMON MISTAKE: PC AND MAR

  • The PC and MAR both hold addresses, not instructions. The MDR holds the instruction or data itself.
  • The PC holds the address of the next instruction, not the current one.
  • The control unit decodes; the ALU does not.

1.1.2 CPU performance

FactorWhat it isEffect on performanceLimits
Clock speedThe number of fetch-execute cycles the CPU can carry out per second, measured in hertz. 3.5 GHz = 3.5 billion cycles per second.Higher clock speed → more instructions executed per second → programs run faster.Faster CPUs produce more heat and use more power. Overclocking can make a CPU unstable.
Cache sizeHow much data and how many instructions the cache can hold.Larger cache → more frequently used data is kept close to the CPU → it waits less often for slower RAM.Cache is expensive. Beyond a point, extra cache gives little benefit.
Number of coresA core is a complete processing unit that can carry out its own fetch-execute cycle. A quad-core CPU has four.More cores → more instructions processed at the same time (in parallel) → better for multitasking and programs written to use several cores.Not every program can be split into parts that run at the same time. Cores must communicate, which takes time. Two cores ≠ twice as fast.
✎ WORKED EXAMPLE: which laptop is faster? Decide yourself, then click. Laptop A: 2 cores, 3.6 GHz, 4 MB cache. Laptop B: 6 cores, 3.0 GHz, 12 MB cache. Used for video editing.

Laptop B is likely to perform better for video editing. Video editing software is written to split work across cores, so B's six cores can process more of the video at the same time. Its 12 MB cache also keeps more frames and instructions close to the CPU, so it waits less for RAM. Laptop A's higher clock speed means each core runs more cycles per second, which helps programs that only use one core, but this is unlikely to outweigh four extra cores for this task.

★ EXAM TIP: EXPLAIN THE CHAIN

  • Don't write "more cores make it faster". Write what each core does: "each core can carry out its own fetch-execute cycle, so more instructions are processed at the same time".
  • For 2 marks, link the factor to the result: factor → what changes in the CPU → effect for the user.
Clock speed
The number of fetch-execute cycles a CPU carries out per second, measured in hertz (e.g. GHz).
Core
An independent processing unit within a CPU that can carry out its own fetch-execute cycle.
Cache size
The amount of data and instructions the cache can store; larger means fewer slow trips to RAM.

1.1.3 Embedded systems

An embedded system is a computer system built into a larger device, designed to carry out one dedicated function (or a small set of functions).

CharacteristicWhy
Dedicated to one taskIt controls one device, e.g. the wash cycle of a washing machine.
Small and cheapMillions are made; the hardware is only as powerful as the task needs.
Low powerMany run from batteries or must not get hot.
ReliableSimple, well-tested hardware and software; some run for years without restarting.
Program usually in ROM (firmware)The program doesn't change, so it is stored permanently. It can be hard or impossible to upgrade.
Limited or no user interfaceA few buttons and a small display, or none at all.

Examples: washing machine, microwave, central heating thermostat, car engine management system, traffic lights, fitness tracker, digital camera, smart doorbell, MRI scanner control.

Not embedded: a laptop, desktop PC or smartphone. These are general-purpose computers that can run many different programs.

★ EXAM TIP

If asked for an example, name the device and what the embedded system does in it: "a dishwasher, where it controls the water temperature and the timing of the wash cycle".

Embedded system
A computer system built into a larger device to carry out a dedicated function.
General-purpose computer
A computer, like a PC or smartphone, that can run many different programs for many different tasks.

Exam-style questions

Allow about 30 minutes. Answer each question before you look at its mark scheme.

State the purpose of the CPU.

  • To process data and instructions / to carry out the fetch-execute cycle (1).

Describe the role of the arithmetic logic unit (ALU).

  • Carries out arithmetic calculations, e.g. addition/subtraction (1).
  • Carries out logical operations/comparisons, e.g. AND, OR, greater than (1).

Describe what is meant by the Von Neumann architecture.

  • Instructions and data are stored in the same memory (1).
  • Instructions are fetched and executed one at a time / uses registers such as PC, MAR, MDR, accumulator (1).

Describe what happens during the fetch stage of the fetch-execute cycle. Name the registers used.

  • The address in the program counter (1) is copied to the MAR (1).
  • The instruction at that address is fetched from memory/RAM into the MDR (1).
  • The program counter is incremented (1).

State the purpose of the accumulator and the memory address register.

  • Accumulator: holds the results of calculations/processing by the ALU (1).
  • MAR: holds the address of the memory location to be read from or written to (1).

Explain why cache improves the performance of a CPU.

  • Cache is faster than RAM / is closer to the CPU (1).
  • Frequently used data/instructions are stored there, so the CPU spends less time waiting for data from RAM (1).

Mia's computer has a dual-core 3.2 GHz CPU. She is thinking of upgrading to a quad-core 3.2 GHz CPU. Explain two reasons why her programs might not run twice as fast.

  • Not all programs/tasks can be split to run in parallel (1) so some cores may be idle while one does all the work (1).
  • Cores need to communicate/coordinate (1) which takes time / creates overhead (1).
  • Accept: other bottlenecks such as RAM or storage speed (1) so the CPU waits for data regardless of cores (1).

Define the term 'clock speed'.

  • The number of fetch-execute cycles / instructions processed (1) per second (1). Accept: measured in hertz/GHz for the second mark.

A smart thermostat contains an embedded system. Describe three characteristics of embedded systems.

  • Any three, 1 each: dedicated to a single/specific task; part of a larger device; small in size; low power consumption; low cost to make; very reliable; program stored in ROM/firmware; limited/no user interface; difficult to upgrade.

Give two examples of devices that contain an embedded system, other than a thermostat.

  • Any two, 1 each: washing machine, microwave, dishwasher, car engine management, traffic lights, fitness tracker, digital camera, sat nav, smart TV, etc. Do not accept: laptop, PC, smartphone.

A games company is choosing a CPU for a new games console. Explain how clock speed, cache size and number of cores will each affect how well games run on the console.

  • Clock speed: higher clock speed means more instructions per second (1) so the game can update frames/physics faster / smoother gameplay (1).
  • Cache: larger cache stores more frequently used game data/instructions (1) so less waiting for RAM / faster loading of repeated tasks (1).
  • Cores: more cores can run tasks in parallel, e.g. graphics, sound and AI at the same time (1) but only if the game is written to use several cores (1).
