2.1.1 Computational thinking

Computational thinking means thinking about a problem in a way that lets a computer help solve it. There are three principles in the specification:

PrincipleMeaningExample: a school sat nav app
AbstractionRemoving unnecessary detail and focusing on what matters for the problemThe map shows roads, corridors and rooms; it leaves out wall colours, furniture and posters
DecompositionBreaking a complex problem down into smaller, more manageable parts that can each be solved separatelySplit into: get the start room, get the destination, find the shortest route, display directions
Algorithmic thinkingWorking out the logical steps needed to solve the problem, in the right orderThe step-by-step method for finding the shortest route between two rooms

Benefits: decomposition makes each part easier to understand, code and test, and parts can be shared across a team and reused. Abstraction makes a problem simpler to solve and the program simpler to use.

2.1.3 Searching algorithms

Try it: algorithm stepper

Linear search

  1. Start at the first item.
  2. Compare it with the item you're looking for.
  3. If it matches, stop: found.
  4. If not, move to the next item and repeat.
  5. If you reach the end of the list without a match, it isn't there.

Works on unsorted lists. Simple, but slow on large lists: in the worst case every item is checked.

Binary search

Pre-requisite: the list must be sorted.

  1. Find the middle item (if there are two, pick either consistently; the code below rounds down).
  2. If it is the item you want, stop: found.
  3. If the item you want is smaller, discard the middle item and everything after it; if larger, discard the middle item and everything before it.
  4. Repeat with the half that's left until the item is found or there's nothing left.

Much faster on large lists: each comparison halves the list. 1,000 items need at most 10 comparisons; a linear search could need 1,000.

ERL Linear search

function linearSearch(items, target)
    for i = 0 to items.length - 1
        if items[i] == target then
            return i
        endif
    next i
    return -1
endfunction

PY Linear search

def linear_search(items, target):
    for i in range(len(items)):
        if items[i] == target:
            return i
    return -1

names = ["Zara", "Ben", "Ola", "Kit", "Amy"]

ERL Binary search

function binarySearch(items, target)
    low = 0
    high = items.length - 1
    while low <= high
        mid = (low + high) DIV 2
        if items[mid] == target then
            return mid
        elseif items[mid] < target then
            low = mid + 1
        else
            high = mid - 1
        endif
    endwhile
    return -1
endfunction

PY Binary search

def binary_search(items, target):
    low = 0
    high = len(items) - 1
    while low <= high:
        mid = (low + high) // 2
        print("Checking index", mid, "=", items[mid])
        if items[mid] == target:
            return mid
        elif items[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

2.1.3 Sorting algorithms

Use the algorithm stepper above to watch each sort.

Bubble sort

  1. Compare the first two items. If they are in the wrong order, swap them.
  2. Move along one place and compare the next pair. Repeat to the end of the list: that is one pass. The largest item is now at the end.
  3. Repeat passes until a whole pass is made with no swaps: the list is sorted.

ERL Bubble sort

procedure bubbleSort(items)
    n = items.length
    do
        swapped = false
        for i = 0 to n - 2
            if items[i] > items[i + 1] then
                temp = items[i]
                items[i] = items[i + 1]
                items[i + 1] = temp
                swapped = true
            endif
        next i
        n = n - 1
    until swapped == false
endprocedure

PY Bubble sort

def bubble_sort(items):
    items = items.copy()
    n = len(items)
    swapped = True
    while swapped:
        swapped = False
        for i in range(n - 1):
            if items[i] > items[i + 1]:
                temp = items[i]
                items[i] = items[i + 1]
                items[i + 1] = temp
                swapped = True
        n = n - 1
        print(items)
    return items

[1, 2, 4, 5, 8]

The third pass makes no swaps, which is how the algorithm knows it's finished.

Insertion sort

  1. The first item is treated as a sorted list of one.
  2. Take the next item and compare it with the items in the sorted part, moving left.
  3. Shift larger items one place right and insert the item in its correct position.
  4. Repeat until every item has been inserted.
def insertion_sort(items):
    items = items.copy()
    for i in range(1, len(items)):
        current = items[i]
        j = i - 1
        while j >= 0 and items[j] > current:
            items[j + 1] = items[j]
            j = j - 1
        items[j + 1] = current
        print("After inserting", current, ":", items)
    return items

After inserting 9 : [3, 7, 9, 1]
After inserting 1 : [1, 3, 7, 9]

Merge sort

  1. Divide: split the list in half, then split each half again, until every sub-list has one item (a list of one is sorted).
  2. Merge: merge pairs of sub-lists into sorted lists twice the size. To merge, compare the first item of each list and move the smaller into the new list; repeat.
  3. Keep merging until there is one sorted list.

You need to be able to describe and trace merge sort, not write it. This Python version prints every merge:

def merge_sort(items):
    if len(items) <= 1:
        return items
    middle = len(items) // 2
    left = merge_sort(items[:middle])
    right = merge_sort(items[middle:])
    merged = []
    i = 0
    j = 0
    while i < len(left) and j < len(right):
        if left[i] <= right[j]:
            merged.append(left[i])
            i = i + 1
        else:
            merged.append(right[j])
            j = j + 1
    merged = merged + left[i:] + right[j:]
    print("Merge", left, "and", right, "->", merged)
    return merged

Merge [4] and [1, 7] -> [1, 4, 7]

★ EXAM TIP: IDENTIFY THE ALGORITHM FROM CODE

  • Binary search: look for low, high and mid.
  • Bubble sort: compares items[i] with items[i + 1] and swaps, with a swapped flag.
  • Insertion sort: stores a current item and shifts items right in an inner while loop.
  • Merge sort: splits into left and right halves and merges.
Bubble sort
A sort that repeatedly compares adjacent pairs and swaps them if in the wrong order, until a pass is made with no swaps.
Insertion sort
A sort that takes each item in turn and inserts it into the correct position in the already sorted part of the list.
Merge sort
A sort that splits a list into single items, then repeatedly merges pairs of sub-lists into sorted order.
Pass
One complete run through the list in a bubble sort.
