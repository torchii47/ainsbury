Write a Python function appointment_cost(consult_type, is_member). A standard consultation costs £45.00 and an emergency consultation costs £120.00. Members receive 10% off. The function should return the cost, or −1 if the consultation type is not recognised.

Spec 2.7.6, 2.4.6

  • Function defined with two parameters (1)
  • Correct price for standard and emergency (1)
  • Returns −1 for an unrecognised type (1)
  • Applies 10% discount for members (1)
  • Returns the cost (1)
  • Correct syntax and indentation throughout (1)

Example answer:

def appointment_cost(consult_type, is_member):
    prices = {"standard": 45.00, "emergency": 120.00}
    if consult_type not in prices:
        return -1
    cost = prices[consult_type]
    if is_member:
        cost = cost * 0.9
    return round(cost, 2)

print(appointment_cost("standard", True))
print(appointment_cost("emergency", False))
print(appointment_cost("dental", False))
