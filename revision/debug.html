Debugging Challenges

Each program has at least one defect. Fix the code, press Check and see which tests pass. It's practice for the fixing defects task in the Employer Set Project.

D

Python self-test

This checks that every faulty program fails its checks and every fixed program passes them. It takes a few minutes, because the last task loads pandas.

TaskFaulty code failsFixed code passes

How it works

  1. Read what the code is meant to do.
  2. Press Check my code and read the results. A FAIL line shows what the code gave and what it should give.
  3. Fix one defect at a time, then check again.
  4. For each defect, say which line it's on and whether it's a syntax, runtime or logic error. See 2.10 Robust code.

Your code runs in your browser and is saved on this device. Python downloads the first time you use it, so you need internet for that. In the real ESP you won't have automatic checks, so get used to choosing your own test data too.
