This is the whole Core Revision Guide, rebuilt as a website you can use on any device. Every page has the notes, tables, worked examples and tested Python code from the printed guide, plus tools to test yourself as you go.

Written for the T Level Technical Qualification in Digital Software Development (Level 3), Pearson specification version 1.1 (August 2026), core component: Paper 1, Paper 2 and the knowledge behind the Employer Set Project.

This guide is an independent teaching resource. It is not produced, checked or endorsed by Pearson or the Joint Council for Qualifications (JCQ). The mock papers are practice papers written in the style of the live assessments. All Python code in this guide has been run and tested in Python 3.10 or later. For use by students on the course. Not for resale.

■ SAVED ON THIS DEVICE

Your checklist ratings, answers, marks and notes are saved in this browser only. They aren't sent anywhere, so nobody else can see them, but they won't follow you to another computer and clearing your browser data deletes them. To move them, use backup_progress.exe below.

How to use this guide

This guide covers everything in the core content for Paper 1 and Paper 2. Each content area follows the same pattern, so you always know where to look.

FeatureWhat it is forOnline, you can...
Section openerThe coloured banner listing what the content area covers and how it links to others.Use the On this page list to jump to any topic.
Spec checklistRate yourself on every specification point: Secure, Unsure or Revise. Start with your 'Revise' topics.Tick a rating. It's saved, and your 'Revise' points appear on this home page.
Topic pagesNotes for every sub-point of the specification, with tables, worked examples and tested Python code.Predict each code output before you reveal it. Copy code to run it yourself.
Quick recallKey definitions for the topic.Cover the definitions, then click each one to check you knew it.
Knowledge organiserOne page of the key facts for the content area. Use it for quick recall before an exam.Use Test me to blur every fact, then reveal them one at a time. Flashcards are built from every definition on the page.
Exam-style questionsPractice questions with marks, in the style of the real papers.Type your answer, reveal the mark scheme, then give yourself a mark to see your score.
Mock papers (Part C)Two full 90-mark papers. Sit them timed.Use the built-in 2 h 15 min timer. Mark schemes unlock when you finish.
Answers (Part D)Mark schemes for every question set and both mock papers.Each mark scheme sits under its own question.
Glossary and indexEvery key term defined in one A–Z list.Filter the glossary, practise with flashcards, or search the whole guide.
