Starter Template

A bare-bones portfolio page to build from. Every line is commented so you can see what it does.

Download the files

💾 index.html 💾 style.css Preview it

If the download doesn't start, right-click the button and choose Save link as...

What's included

  • The full HTML5 page structure: <head>, <body> and all the meta tags you need
  • Semantic layout: <header>, <nav>, <main>, <section> and <footer>
  • A project "card" you can copy for each project
  • CSS colour variables so you can re-theme the site by changing 4 lines
  • A media query for small screens

How to use it

  1. Make a folder for your site and save both files into it.
  2. Make an images folder inside it for your pictures.
  3. Open index.html in your editor and replace the placeholder text.
  4. Make more pages (e.g. about.html) by copying index.html and changing the content and <title>.
  5. Change the colours at the top of style.css, then make the design your own.
  6. Upload everything to your Neocities dashboard, keeping the same folder structure.
