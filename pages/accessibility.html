Accessibility

I want every student to be able to use this site. This page explains what works, what doesn't yet and how to get help. Last updated 6 November 2026.

What the site does

  • Skip links let keyboard users jump straight to the main content.
  • Pages are built to adapt to phones and browser zoom.
  • If your device is set to reduce motion, the scrolling text and blinking labels stop.
  • Guide colours are always backed up with text labels, so you don't need to rely on colour.
  • Images used to give information have text descriptions.

How much it's been tested

The aim is to meet WCAG 2.2 at level AA. The site's code and main colours have been checked with automated tests, but it hasn't had a full test with a screen reader or a formal audit, so I can't say that it fully meets that standard yet.

Known problems

  • Retro fonts: some titles use pixel-style fonts, which may be harder to read. Main text uses a standard font.
  • Scrolling text: the homepage banner only pauses when you hover over it, unless your device is set to reduce motion.
  • Code editors: pressing Tab in a code box may move you out of the box rather than adding an indent. Use spaces instead.
  • Charts and diagrams: some may not have a full text alternative yet.
  • Headings: some note boxes skip a heading level, which may be confusing with a screen reader.
  • CargoPulse: this is a demo for a lesson, and it hasn't been checked for accessibility.

Need something different?

If you can't use part of this site, please tell me using the report a problem page. Say which page you were on and what happened, and I'll try to help. You can also ask your teacher or your school or college's learning support team.
